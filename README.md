# 💖 Gas Theory of Love 💖

A fun, interactive website explaining the **Gas Theory of Love** — an absurd yet relatable pseudo-scientific theory inspired by Sukumar Ray's *Abol Tabol*.

"Love is not a spark. Love is invisible pink gas."

## 🎈 About The Project

This website turns the "Gas Theory of Love" into an engaging, pink-themed interactive experience. It explains how love enters like gas (PUFF!), builds pressure, leaks (FWOOSH!), dramatically pops during breakups, and always comes back (RE-PUFF!).

Perfect for presentations, reels, or just sharing the chaos.

### Features
- Fully responsive pink-themed design
- Interactive balloon that inflates, pops, and re-puffs
- Clean explanation of all phases of the theory
- Fun Abol Tabol-inspired nonsense
- No external dependencies (just Tailwind CDN)

## 📸 Preview

- Hero section with clickable balloon
- Theory breakdown with phases
- Interactive "Inflate Your Own Heart" lab
- Mobile-friendly design

## 🚀 How to Run

1. Download or copy the `index.html` file
2. Open the file in any web browser (Chrome, Firefox, Edge, etc.)
3. No installation or server needed!

## 🧪 The Theory

**Valentine-Gas Law:**
$$
P_L = k \cdot \frac{A \times T}{E}
$$

Where:
- $P_L$ = Pressure of Love
- $A$ = Attachment
- $T$ = Time
- $E$ = Emotional Stability
- $k$ = Abol Tabol Constant
